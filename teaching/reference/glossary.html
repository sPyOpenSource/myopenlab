Module system

TermMeaningWhere in code
Module / ElementA directory under Elements/ containing a definition.def, src/, bin/, icon and descriptions. The unit the palette shows and the user drags onto a canvas.distribution/Elements/
definition.defKey-value metadata file (KEY = value). Says whether a dir is a category (ISDIRECTORY = TRUE) or a leaf element, plus localized captions, the Java class to load, and the icon.src/VisualLogic/Tools.java:641
classCircuitThe Java class (no package prefix) that implements the element's logic. Loaded by reflection from bin/.src/VisualLogic/Element.java:653
classfrontThe Java class for the front-panel (GUI) side of an element. Usually empty for circuit elements.src/VisualLogic/Tools.java:611
Element (class)The GUI wrapper: a JPanel that draws pins, wires, border, label. Implements ExternalIF — the interface the module's code uses to control it.src/VisualLogic/Element.java
JVSMainBase class every module's logic class extends. Implements ElementIF. Holds public ExternalIF element; and the lifecycle methods.src/tools/JVSMain.java
LoaderBuilds a URLClassLoader over the element's bin/ dirs and instantiates the class via newInstance().src/VisualLogic/Loader.java

Runtime model

TermMeaningWhere in code
VMVirtual Machine — a canvas (circuit = logic, or front panel = UI) that owns elements and wires. Not a Java VM.src/VisualLogic/VMObject.java
PinA connection point on an element's edge. Has an index, a data type, and an I/O direction (PIN_INPUT / PIN_OUTPUT).src/VisualLogic/ExternalIF.java:69
Draht (wire)Connects a source pin to a destination pin. When a source writes an output, its wire is queued in the VM's processList.src/VisualLogic/Draht.java
processListThe event queue of wires awaiting delivery. The run loop pops one, finds its destination element, and calls xonProcess().src/VisualLogic/VMObject.java:1781
process()Runs on the destination element each time new data arrives on a wire. The core of the event-driven model.src/VisualLogic/VMObject.java:1843
processClock()Runs periodically for elements that registered via element.jNotifyMeForClock().src/VisualLogic/VMObject.java:1685

Data types & variables

TermMeaningWhere in code
VSObject (+ subclasses)Base of all pin-value objects: VSBoolean, VSString, VSInteger, VSDouble, VSColor, VSImage, VSFlowInfo, 1D/2D arrays, etc.src/VisualLogic/variables/
changed flagEach VSObject carries isChanged(); setValue() sets it. The VM resets all flags after each cycle. Elements react only to fresh data.src/VisualLogic/variables/VSObject.java:57
C_* type constantsPin data-type ids: C_BOOLEAN, C_INTEGER, C_DOUBLE, C_STRING, C_ARRAY1D_*, C_VARIANT, …src/VisualLogic/ExternalIF.java:38
copyReferenceFromWires share the same VS object reference with the destination, so both sides see the same value and changed-flag.src/VisualLogic/variables/VSBoolean.java:60

Lifecycle methods (on a JVSMain subclass)

MethodWhen it runs
init()Once, at placement: declares pins, size, icon, captions.
initInputPins() / initOutputPins()Binds the module's VS* fields to pin references.
process()Each time a wire delivers data to this element.
processClock()Periodically, if clock-registered.
start() / stop()Simulation start / stop.
paint(Graphics)Custom drawing of the element on the canvas.
onDispose()Element destroyed — release resources.
openPropertyDialog()User opens the property editor.
saveToStream() / loadFromStream()Persist / restore state in the project file.
